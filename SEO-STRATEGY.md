# Everpine Events — On-site SEO strategy

This document explains the SEO built into the site and how to keep it working each year. Off-site work that needs the owner's own accounts (Search Console, Google Business Profile, citations, reviews, links) is in `LAUNCH-KIT.md`.

> **About the numbers.** No keyword-volume tool was available for this project. Every demand or difficulty figure below is a **relative estimate** (High / Med / Low), based on live UAE Google autocomplete, SERP composition and competitor investment (researched Sept 2026). None of it is measured data. Replace the estimates with real Search Console impressions once the site has 4–6 weeks of data.

---

## 1. Where we can win

- **Price transparency.** Premium competitors (Irony Home, Bella Entertainment, Clairvoyant) don't publish prices, and the generalists only say "from AED 199". Everpine's three priced packages answer "price / cost" intent directly, and they are the only valid `Offer` markup in this niche.
- **Depth and a real portfolio.** The Dubai SERP is dominated by handyman and facility-management generalists, for whom Christmas is one page among a hundred. Each of our service pages has specific, useful content and real installation photos.
- **Sharjah.** No dedicated Christmas-décor service provider ranks for Sharjah service queries. A genuinely useful Sharjah page can rank quickly.
- **"Near me" is won in the map pack**, not on the page. That is why the Google Business Profile (in `LAUNCH-KIT.md`) matters as much as the site.

## 4. Internal linking

- **Header:** Packages · Services · For businesses · Dubai · Sharjah · Gallery · FAQ · Get a quote.
- **Footer:**
  - every service page
  - both city pages
  - both guides
  - About, Gallery, FAQ, Contact, Privacy
- **Service pages:**
  - link to the packages that include them (pine "Included in" band)
  - have 2–3 related links and "Also in Dubai / Sharjah"
  - carry in-text links to guides
- **City pages:** link in the text to packages, services and the other city.
- **Home:** in-text anchors to both city pages, the full services index, and a package teaser that links to `/packages#basic|silver|gold`.
- **Breadcrumbs** appear on every inner page, as visible links plus `BreadcrumbList` markup.
- **No orphans:** all 21 URLs are in `sitemap.xml` and are linked from at least two places.

## 5. Structured data

All JSON-LD is typed with `schema-dts` (`lib/schema.ts`) and checked after every build by `scripts/validate-schema.mjs`.

| Type | Where | Notes |
|---|---|---|
| `LocalBusiness` (`/#business`) | every page | Service-area business with `areaServed` Dubai + Sharjah, `priceRange`, logo and image. **No address, by design.** `telephone`, `email`, `sameAs` and `legalName` appear automatically once set in `site-config.ts`. Google's local rich results expect an address, so rely on the Business Profile for the map pack. |
| `WebSite` | every page | Publisher → business. |
| `Service` + `Offer` ×3 (AED) | `/`, `/packages` | Each Offer: price, `priceCurrency: AED`, `areaServed`, `itemOffered` Service with contents. |
| `Service` | each service page, commercial, city pages | `provider` → business; city pages scope `areaServed` to that city. |
| `FAQPage` | `/faq` (all questions), service pages, city pages, commercial, guides | Only questions visible on that page, and each question marked up once: home and `/packages` show pricing FAQs but don't mark them up, because `/faq` does. Google has limited FAQ rich results to authoritative government and health sites since 2023, so this markup is for understanding, not snippets. |
| `BreadcrumbList` | every inner page | Matches the visible breadcrumb. |
| `Article` | both guides | `author` / `publisher` → business; `dateModified`. |
| `ImageGallery` | `/gallery` | First 12 photos with captions. |
| `ItemList` | `/services` | Service pages. |
| `AboutPage` / `ContactPage` | about, contact | About → business. |

**Never included:** reviews, ratings, awards, founding date, opening hours or address. Add `aggregateRating` only when genuine Google reviews exist, and even then only as permitted by Google's self-serving review guidelines, which currently disallow it for a LocalBusiness's own site.

**After launch, test every template** in Google's Rich Results Test and the Schema.org validator.

## 6. Technical foundations

- **Static generation.** Every page is prerendered, so the HTML is complete for crawlers.
- **Canonical URLs.** Canonicals come from `NEXT_PUBLIC_SITE_URL`, and the production build **fails** if that is missing or a placeholder.
- **Indexing:**
  - Only production on the real domain is indexable.
  - Vercel previews get `noindex` and a disallow-all `robots.txt`.
  - `/en/*` 308-redirects to the unprefixed URL.
  - Unknown URLs return a real 404 with `noindex`.
- **Sitemap and robots.** `sitemap.xml` has hreflang alternates and a stable `lastmod` (`contentUpdated` in `site-config.ts`; update it when copy changes). `robots.txt` points to the sitemap.
- **Social images.** Each page gets a 1200×630 OG/Twitter image generated at build time, with the brand serif and a real photo.
- **Images:**
  - `next/image` with WebP, correct `sizes`, and descriptive filenames and alt text
  - `priority` + `fetchpriority=high` only on each page's LCP image
  - blur placeholder only on that image, because blur SVGs cost main-thread time
- **Fonts.** Self-hosted with `next/font` and metric-matched fallbacks (CLS 0): Cormorant Garamond for display, Hanken Grotesk for text.
- **JavaScript.** Validation runs on the server only (zod never ships to the browser). Scroll reveals use CSS scroll-driven animation, with no JS and no INP cost.
- **Security headers:** CSP, HSTS, `X-Frame-Options`, `Referrer-Policy`, `Permissions-Policy`, COOP.

**Honest reading:**

- Accessibility, Best Practices and SEO are 100 everywhere, and CLS is 0 everywhere.
- Performance is 87–96, below the ≥95 target on most pages.
- The redesign's richer visual layer costs roughly 3–6 points against the earlier plain version, which scored 91–97. That layer is two display-font files, a decorative canvas and a blurred header.
- The gap is Lighthouse's *simulated* slow-4G LCP. Unthrottled, LCP is well under 1 s.
- Served from Vercel's edge the numbers typically improve. Check PageSpeed Insights and the Search Console Core Web Vitals (field) report after launch.
- If field LCP exceeds 2.5 s, the quickest levers, in order, are:
  1. Turn off the fairy-light canvas on mobile (`components/Bokeh.tsx`).
  2. Drop the serif italic preload (`app/fonts.ts`). This trades a small font swap for speed.
  3. Serve a smaller mobile hero crop.

## 7. Annual content calendar

Christmas search demand in the UAE builds from autumn. Everything customer-facing should be refreshed **by 1 September each year** so Google has recrawled it before demand peaks.

| When | Task | Pages / files |
|---|---|---|
| **July** | Review last season: Search Console queries, top pages, form and WhatsApp conversions. Note new queries worth a page or FAQ. | Search Console, Vercel Analytics |
| **By mid-Aug** | Confirm prices and package contents for the new season. Update `packages` in `site-config.ts` and any price mentions in copy (home FAQ, `/packages`, tree page price section, Dubai FAQ). | `lib/site-config.ts`, `content/en/*` |
| **By mid-Aug** | Add the best new photos from last season (descriptive filenames, honest alt text). Rotate the home plates and package images. Retire weaker photos. | `assets/images`, `content/en/images.ts` |
| **By 1 Sept** | Refresh the two guides (facts, links; add a new FAQ from real customer questions). Update `dateModified` in the guide pages. Update `contentUpdated` in `site-config.ts`. | guides, `site-config.ts` |
| **By 1 Sept** | Redeploy so the season eyebrow shows the new year. `season.mode: 'auto'` switches to "booking" from August. | Vercel |
| **By 1 Sept** | Publish one new genuinely useful guide if last season's questions justify it. Candidates: *villa exterior lighting: what to check with your community*; *real vs artificial trees in UAE homes* (only once the tree type is confirmed); *planning Christmas décor for a restaurant*. | new `content/en` entry + route |
| **Sept** | Google Business Profile: new photos, first seasonal post, check services and prices. See `LAUNCH-KIT.md`. | GBP |
| **Oct–Nov** | Weekly GBP posts. Request reviews after each installation. Outreach to lifestyle media for Christmas-guide inclusion. | GBP, outreach |
| **1–25 Dec** | Mode auto-switches to "in-season" ("ask about remaining dates"). Push removal bookings. | automatic |
| **26 Dec onwards** | Mode auto-switches to "off-season" ("now booking for next Christmas"). Push removal; ask for reviews. | automatic |
| **Jan** | Removal season. Collect photos (with client permission) and review requests. | — |

**Every year:** check that all prices, claims and photos are still accurate, and never add invented reviews, counts or awards.
